# Scope

## Current scope
Only governance bootstrap is in scope:
- checkpoint and cross-chat handoff;
- canonical source hierarchy;
- Work Order and prompt delivery contract;
- review/evidence verdict model;
- minimal Source Pack placeholders required before future implementation.

## Out of scope for HCT-BOOT-0001
- trading strategies;
- exchange selection or integration;
- API keys, secrets or custody;
- order execution;
- portfolio/risk algorithms;
- UI/runtime architecture;
- production deployment.

Those topics require explicit planning increments after this bootstrap is approved.
