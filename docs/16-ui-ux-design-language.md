# UI/UX Design Language

Status: `DISCOVERY_IN_PROGRESS`
Increment: `HCT-PLAN-0001`

Hive Crypto Trader should share the recognizable visual DNA being established across the company's products, with Hive Plan as a reference direction rather than a literal clone.

## Design intent
- technological, premium and enterprise-grade visual language;
- dark-first trading cockpit with high information density without visual clutter;
- selective 3D/depth effects, glass/metal/volumetric cues and motion used to reinforce hierarchy rather than decorate indiscriminately;
- strong realtime visual feedback for market state, execution, connectivity, risk, incidents and learning status;
- consistent component system, typography, spacing, iconography, motion and accessibility tokens;
- responsive desktop-first operations surface, with later mobile/read-only operational views evaluated separately;
- tenant-aware branding/entitlement architecture may be added later without breaking the core design system.

## Core screens to plan later
- realtime command center / trading cockpit;
- market universe scanner and opportunity ranking;
- symbol intelligence workspace;
- indicators/patterns/strategy evidence view;
- positions, orders and execution health;
- risk, leverage and portfolio exposure;
- Safety Governor / incidents / kill-switch state;
- RAG memory and decision trace explorer;
- backtest/replay/paper-trading laboratory;
- model/strategy/version lifecycle;
- tenant/account administration;
- system health, API quotas, WebSocket sessions and cache freshness;
- audit/evidence and diagnostics.

## Product rule
A beautiful dashboard must never hide risk. Safety, stale data, uncertain exchange state, API degradation and account discrepancies receive higher visual priority than profit-oriented decoration.
